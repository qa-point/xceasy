# ADR 0021: диагностические детали и приватность учётных данных

Статус: принято 09.09.2026 после обсуждения с сопровождающим.

## Контекст

Для объяснения падений UI-тестам нужны скриншоты, значения полей, дерево UI и явный debug output. Существующие regex-правила не гарантируют удаления всех секретов и персональных данных.

## Решение

Сохранить текущую диагностику. Точечно фильтровать поддерживаемые формы учётных данных в текстовых sinks, не логировать raw HTTP headers/body и инфраструктурные секреты, описывать ограничения фильтра. Синтетические аккаунты, доступ и сроки хранения артефактов определяет потребитель. Тотальное маскирование UI и отключение evidence требуют явного требования; новые runtime-настройки здесь не реализуются.

## Последствия

Конституция 2.0, F04, технические/security guides и инструкции агентов описывают эту границу. Известные пробелы фильтра можно исправлять отдельно с точечными regression tests. Swift API, runtime-поведение, схема артефактов и опубликованные релизы здесь не меняются.
