# XCEasy Integration Fixture

[Russian version](README_RU.md)

This is an internal technical fixture of the XCEasy repository. It is not a public sample application and is not intended to be copied by framework users.

The fixture verifies XCEasy against real UIKit and SwiftUI accessibility trees, contributes integration coverage, and hosts reproducible regression scenarios.

Run it from the framework repository root:

```bash
./scripts/check.sh fixture
```

Public independent UIKit and SwiftUI examples live in the separate `xceasy-examples` repository.
